# Security Policy

## About this project

Unimos Costa Blanca is a community initiative advocating for safer pedestrian crossings in Costablanca, Castellbisbal.

## Reporting a Vulnerability

If you discover a security issue affecting this website, please report it privately through GitHub's security reporting feature, if available.

Please do not publish security vulnerabilities or disclose personal information.

## Personal Data

This website does not directly collect petition signatures. Signatures are collected through a separate Google Forms form.

The public signature counter must only display the total number of supporters and must never expose personal data from the form or spreadsheet.
